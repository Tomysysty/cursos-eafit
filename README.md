# Cursos en EAFIT

Trabajos más pequeños de los primeros semestres de Ingeniería de Sistemas, reunidos en un solo lugar.

| Carpeta | Curso | Qué hay |
|---|---|---|
| [`probabilidad-r/`](probabilidad-r) | Probabilidad y Estadística (CM0244), 2025 | Laboratorios y examen en R Markdown: análisis de datos de calidad del vino tinto y de producción de energía renovable |
| [`java/api-rest-swing/`](java/api-rest-swing) | Java, 2024 | Interfaz en Swing con botones GET, POST y PUT para una API REST simulada en Java puro, sin frameworks. La API base venía del curso; la ventana es mía |
| [`java/calculadora/`](java/calculadora) | Java, 2024 | Las cuatro operaciones con dos enteros, validando la división por cero |
| [`cpp-transposicion/`](cpp-transposicion) | C++, 2025 | Mi parte de un proyecto en equipo: el cifrado por transposición columnar. El resto del proyecto (Enigma, Vigenère, Rail Fence, Hill) está en el repositorio privado del equipo |

Más trabajos del inicio de la carrera en [FUNDAMENTOS-DE-PROGRAMACION](https://github.com/Tomysysty/FUNDAMENTOS-DE-PROGRAMACION).
